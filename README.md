# Youtube Bookmarker

Chrome extension that bookmarks timestamps in YouTube videos and jumps back to the exact moment, then plays from there.

## Install in Chrome

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this `Youtube Bookmarker` folder

## Use

1. Play a YouTube video.
2. Open the extension and click **Bookmark current timestamp**, or click the bookmark icon on the YouTube player controls.
3. Click a saved timestamp to open YouTube at that time and start playback.
